Default Edit Pivots

The master switch

Green means Pivot++ is driving Unity's transform handles. Click it to fall back to the default pivot at any time — your offsets and saved pivots stay exactly where you left them.

One quick offset for the whole selection

The Shared Pivot is a fast, selection-wide offset. It applies to whatever you have selected right now and is shared across every object in that selection.

Bounded thinks in proportions

In Bounded mode the offset is expressed relative to the object's bounds. Each slider places the pivot inside them: -1 is one face, 0 is dead centre, and 1 is the opposite face. Set it once and it lands correctly on a pebble or a skyscraper.

Unbounded thinks in units

Switch to Unbounded to work in fixed distances in the object's local space. Type the precise offset of the pivot from the object's centre in scene units — no slider, no rounding, just the number you want. Perfect for placing a pivot outside the mesh entirely, or matching a measurement from another tool.

Scale-aware offsets

Unbounded only. Ticked, the offset is multiplied by the object's scale. Unticked, it stays an absolute world-distance offset regardless of how the object is scaled.

Save pivots that stay put

Object Pivots are per-object and permanent. Create as many custom pivots as an object needs — a lid, a handle, a base — and they're still there the next time you open the scene.

Default moves the object

With Default selected, the handles behave normally — grab the object and manipulate it around its active pivot.

Edit moves the pivots

Switch to Edit Pivots and the handles move and rotate the saved pivots themselves. This is also where you delete the ones you no longer need. Ctrl + Z undoes the whole way.

Bank the current pivot

Add New Pivot saves the current Shared Pivot position as a new permanent pivot on the selected object. Line it up once, save it, and reuse it forever.
